# Read BGM

Read geometry and full topology from BGM files.

## Usage

``` r
bgmfile(x, ...)

read_bgm(x, ...)
```

## Arguments

- x:

  path to a bgm file

- ...:

  ignored for now

## Value

A list of linked tables: \`vertices\`, \`facesXverts\`, \`faces\`,
\`facesXboxes\`, \`boxesXverts\`, \`boxes\` and \`boundaryvertices\`,
which preserve the topology of the file, plus \`extra\`, which holds the
remaining file information (such as the projection).

## Details

BGM is a file format used for the 'Box Geometry Model' in the Atlantis
Ecosystem Model. This function reads everything from the .bgm file and
returns it as linked tables.

## See also

See helper functions to convert the bgm tables to \`Spatial\` objects,
[`boxSpatial`](https://australianantarcticdivision.github.io/rbgm/reference/rbgm-Spatial.md),
[`faceSpatial`](https://australianantarcticdivision.github.io/rbgm/reference/rbgm-Spatial.md),
[`nodeSpatial`](https://australianantarcticdivision.github.io/rbgm/reference/nodeSpatial.md),
[`boundarySpatial`](https://australianantarcticdivision.github.io/rbgm/reference/rbgm-Spatial.md),
[`pointSpatial`](https://australianantarcticdivision.github.io/rbgm/reference/nodeSpatial.md)
